# 1. COMMAND ARCHITECTURE

Every command must remain modular.

Place group commands in:

src/commands/admin/

Do not put them all in one file.

Use the existing command interface and command loader.

Every command must contain proper metadata:

* name
* aliases
* category
* description
* usage
* permissions

---

# 2. GROUP VALIDATION

Create/use a reusable helper:

isGroup()

If a group-only command is used in a private chat, return:

❌ This command can only be used in a group.

Do not crash.

---

# 3. ADMIN PERMISSIONS

Create/use:

isGroupAdmin()

isBotAdmin()

Commands that modify group membership or delete messages must require the sender to be a group administrator.

If the sender isn't an admin:

❌ Only group admins can use this command.

If the bot needs admin privileges and isn't an admin:

⚠️ I need to be a group admin to perform this action.

Do not attempt unauthorized operations.

---

# 4. ANTILINK

Implement:

.antilink

.antilink on
.antilink off
.antilink delete
.antilink warn
.antilink kick

Store settings separately for every group.

Default:

OFF

Modes:

delete
warn
kick

Detect common URLs including:

http://
https://
[www](http://www).

Also detect common social/invite links such as:

WhatsApp
Telegram
Instagram
TikTok
Facebook
YouTube
Discord

Use a proper URL detection utility.

Do not detect ordinary text containing random punctuation as a link.

Administrators should be exempt.

The bot should only act when antilink is enabled.

Create a reusable function:

detectLinks(text)

which returns whether the message contains a detectable link.

Create a reusable configuration helper for group antilink settings.

# 11. WARNING SYSTEM

Implement:

.warn @user

.warnings @user

.resetwarn @user

Store warnings in SQLite.

Each warning should contain:

* group JID
* user JID
* warning count
* updated timestamp

Warnings must be isolated per group.

Example:

⚠️ @user has been warned.

Warnings: 2/3

Create a configurable warning threshold.

Default:

3 warnings

At the threshold, prepare the system to support an automatic action.

For now, use:

3 warnings → kick

but only actually perform the kick when the bot has permission.

Do not crash if the bot lacks permission.
